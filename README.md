# Пригоди Майї

Лагідна інтерактивна книжечка для перших кроків у читанні українською.
Лисичка-помічниця веде дитину чарівним лісом: від упізнавання букв і звуків до складів і перших слів.

**Онлайн:** https://dovbush-olha.github.io/maya-reading/
Кожен push у `main` перевіряється (типи, лінт, тести) і автоматично публікується на GitHub Pages.

## Як запустити

```bash
npm install
npm run dev
```

Відкрийте http://localhost:5173 у браузері.

На телефоні в тій самій Wi-Fi мережі: `npm run phone` і відкрийте адресу «Network», яку покаже команда (наприклад, `http://192.168.0.79:5173`).
Так можна гратися, але запис голосу й офлайн-режим працюють лише через https (див. нижче).

### Телефон як застосунок

`npm run build` створює папку `dist/` - звичайний статичний сайт без сервера.
Якщо викласти її на будь-який https-хостинг (GitHub Pages, Netlify, Cloudflare Pages), на телефоні можна «Додати на головний екран»: застосунок відкривається з іконки, працює без інтернету, і доступний запис голосу.
Прогрес зберігається на кожному пристрої окремо.

Інші команди:

- `npm test` - перевірка контенту й логіки (усі слова лише з доступних букв, без Я/Ю/Є/Ї тощо).
- `npm run typecheck` і `npm run lint` - типи й лінтер.
- `npm run build` - продакшн-збірка в `dist/`, `npm run preview` - перегляд збірки.

## Як влаштовано

```

    words.ts      банк справжніх слів зі складами та картинками
    week1.ts      7 днів × 2 місії
    phrases.ts    фрази звіра-помічника в бульбашці (без назв букв)
    helpers.ts    звірі, яких можна обрати: лисичка, зайчик, ведмедик, котик, совеня
    validate.ts   перевірка вправ і місій
  logic/          чиста логіка без інтерфейсу

    srs.ts        інтервальне повторення (коробки Лейтнера)
    generate.ts   розминка перед місією і «Повторення в лісі»
    solo.ts       перетворення вправ, коли дитина грається сама
    availability.ts  які місії відкриті, що рекомендувати, чи час нової букви
    voice.ts      які склади й слова дорослий може записати своїм голосом
  components/exercises/  по компоненту на вид вправи
  screens/        Home, MissionPlayer, Parent
```

### Як додати вправу чи місію

Компоненти змінювати не потрібно.
Додайте вправу в `exercises` потрібної місії у `src/content/week1.ts`, наприклад `syllable('ла')` або `build('лама', ['ло'])`.
Нове слово спершу додайте в `src/content/words.ts` разом зі складами й картинкою.
Запустіть `npm test`: тест підкаже, якщо слово містить букву, якої немає в `requires` місії, або якщо в нього немає запису в банку слів.

Нова місія - це ще один об'єкт `Mission` у `WEEK_1` (або новий масив для наступного тижня).

## Порядок букв першого тижня

1. Голосні А, О, У, І, Е, И.
2. Л - перша приголосна (два дні, багато слів: «алло», «Алла», «Лола», «у Олі»).
3. М окремо, потім М разом з Л («мала», «мило», «Міла», «Мама мила»).
4. С, потім Н, потім К - щоразу зі словами з усіх попередніх букв.

Голосні й Л доступні з початку; М, С, Н, К відкриває дорослий у батьківському режимі.

## Два режими

- **Сама** (за замовчуванням, для телефона): слово - «прочитай і знайди картинку» (перевіряється автоматично), склад - кнопка «Прочитала!», звук букви - ваш запис, а без запису - пошук букви за зразком; скласти слово можна за однозначною картинкою.
- **З дорослим**: дорослий бачить, що сказати, і відмічає «Прочитала сама» / «Прочитали разом».

Синтезатора мовлення немає: звуки букв вимовляє дорослий наживо або власним записом (батьківський режим → Налаштування → «Ваш голос для звуків»).
Так само дорослий може записати склади й слова з місій («Ваш голос для складів і слів»): у вправі з'являється 🔊, а склади з дужками можна торкнути й почути, як правильно.
Склад з однієї букви («О-лі») звучить записом звуку цієї букви.

## Методика в застосунку

- Звуки, а не назви букв: дорослий бачить підказку «скажіть звук [м] - протяжно, губки разом».
- За кожне завдання - зірочка в баночку; за місію - наліпка лісового друга. Зірочки ніколи не забираються.
- Голосні червоні, приголосні сині, як у шкільному букварі (у вправах на впізнавання букви всі однакові, щоб колір не підказував).
- Поступові підказки: після першої помилки - підказка про форму або звук, після другої - правильна відповідь світиться.
- Слово одразу розділене на склади з дужками (склад - на звуки), поруч 🔊 із записом дорослого. У налаштуваннях («Підказка одразу на екрані») це можна вимкнути - тоді все з'являється лише після «💡 Підказка».
  Послухати запис - це теж підказка: так і рахується.
  У «прочитай і знайди картинку» 🔊 з'являється лише після підказки чи помилки, щоб картинку не шукали на слух.
- Жодних таймерів, балів чи «неправильних» звуків.
- Дорослий відмічає читання кнопками «Прочитала сама» / «Прочитали разом» - автоматичної оцінки вимови немає.
- Картинка до слова з'являється лише після читання.
- Інтервальне повторення: на початку місії - розминка з буквою, якій настав час.
- Нові букви (С, Н, Л, К та інші) відкриває лише дорослий; програма лише радить, коли дитина готова.
- Якщо в місії знадобилося багато підказок, головний екран запропонує її повторити (не більше трьох разів поспіль).

## Батьківський режим

Кнопка «Для дорослих» (🔑) просить набрати цифрами число, написане словами (наприклад, «сорок сім») - дорослий робить це за секунду, а дитина, яка тільки вчиться читати, випадково не відкриє.
Там можна: позначати статус букв, відкривати нові букви, переглядати й додавати відмітки читання складів, бачити прогрес, запускати будь-яку місію, обирати режим (сама / з дорослим), день чи ніч, звіра-друга, звуки, великі букви чи як у книжці, чи показувати підказку одразу, і записати свій голос для звуків, складів і слів.
